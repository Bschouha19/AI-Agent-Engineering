# Reference Materials

Quick-lookup reference docs for Agent Engineering. These are designed to be open in a second tab while you build — not for learning from scratch, but for looking things up without leaving your editor.

All 10 documents exist and are current as of 2026-07-11.

---

| # | Document | Use it when... |
|---|----------|---------------|
| 01 | Agent Framework Comparison | Choosing between LangGraph, Claude Agent SDK, OpenAI Agents SDK, CrewAI, Microsoft Agent Framework, Google ADK |
| 02 | Reasoning Pattern Cheat Sheet | Deciding ReAct vs. plan-and-execute vs. reflection for an agent's reasoning loop |
| 03 | A2A Protocol Reference | Implementing or debugging agent-to-agent communication |
| 04 | MCP vs. A2A Decision Guide | Deciding whether a given integration needs tool-serving (MCP), agent-to-agent communication (A2A), or both |
| 05 | Memory Systems Comparison | Choosing a persistent agent memory approach (Mem0 or alternatives) |
| 06 | Multi-Agent Topology Comparison | Choosing supervisor/worker vs. hierarchical vs. swarm orchestration |
| 07 | Agent Evaluation Metrics | Building or interpreting a trajectory-level agent evaluation harness |
| 08 | Agentic Security Checklist | Pre-launch review — excessive agency, sandboxing, agent identity |
| 09 | Agent Sandboxing Comparison | Choosing an execution sandbox for untrusted or high-capability agent actions |
| 10 | Production Agent Deployment Checklist | Taking a single agent or multi-agent system from dev to production |

All documents will be verified against current framework docs, protocol specs, and benchmarks as of their writing date. Agent tooling evolves quickly — check the "Verified" date at the bottom of each document and confirm against current sources if in doubt.
